## What is CarPipe?

**CarPipe** is a specialized fork of NewPipe designed specifically for automotive use. This project takes the solid foundation of NewPipe and optimizes it to provide a video and audio streaming experience optimized for car screens and Android Auto.

### Main automotive optimizations:

- **🎯 Vehicle-adapted interface**: UI elements redesigned for car screens
- **📱 Forced landscape orientation**: Optimized for horizontal screens typical of vehicles
- **🔍 Enlarged UI elements**: Larger buttons and text for safe use while driving
- **🚗 Optimized graphic resources**: Icons and drawables specific for automotive environments
- **⚡ Optimized dimensions**: Element sizes adjusted exclusively for automotive use
- **🎨 Automotive styles**: Specific themes and styles for CarPipe

## Automotive Optimizations

CarPipe includes specific optimizations for automotive use based on the changes implemented in this fork:

### UI/UX Optimizations
- **Complete rebranding**: Brand change from NewPipe to CarPipe with automotive visual identity
- **Enlarged UI elements**: 50% increase in element sizes for better visibility on car screens
- **Forced orientation**: All activities are displayed exclusively in landscape mode for horizontal screens
- **Optimized TabLayout**: More compact tab design suitable for automotive environments
- **Balanced icons and text**: Adjustments in icon and text sizes for better readability

### Specialized Resources
- **Automotive drawables**: Specific graphic resources for vehicle use
- **Automotive styles**: Themes and styles optimized for CarPipe
- **Exclusive dimensions**: Element sizes adjusted exclusively for automotive use
- **Landscape resource removal**: Cleanup of orientation-specific resources to optimize size

### Android Auto Compatibility
- **Android Auto optimization**: Interface adapted to work perfectly on Android Auto systems
- **Simplified navigation**: Larger controls easier to use while driving
- **Improved user experience**: Design focused on safety and ease of use in vehicles

## Features

CarPipe maintains all the original NewPipe features while being optimized for automotive use:

* Watch videos at resolutions up to 4K
* Listen to audio in the background, only loading the audio stream to save data
* Popup mode (floating player, aka Picture-in-Picture)
* Watch live streams
* Show/hide subtitles/closed captions
* Search videos and audios
* Enqueue videos (and optionally save them as local playlists)
* Show/hide general information about videos (such as description and tags)
* Show/hide next/related videos
* Show/hide comments
* Search videos, audios, channels, playlists and albums
* Browse videos and audios within a channel
* Subscribe to channels (yes, without logging into any account!)
* Get notifications about new videos from channels you're subscribed to
* Create and edit channel groups (for easier browsing and management)
* Browse video feeds generated from your channel groups
* View and search your watch history
* Search and watch playlists
* Create and edit local playlists
* Download videos/audios/subtitles (closed captions)
* Open in Kodi
* Watch/Block age-restricted material

### Supported Services

CarPipe supports the same services as NewPipe:

* YouTube and YouTube Music
* PeerTube and all its instances
* Bandcamp
* SoundCloud
* media.ccc.de
